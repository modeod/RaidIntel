# Передача работы

Обновляешь `HANDOFF.md` так, чтобы агент, который откроет репозиторий **с нуля**,
понял состояние за минуту и не переделал уже сделанное.

## Сначала — факты, потом текст

```
git status --short
git log --oneline -5
git branch --show-current
```

Пиши в файл **реальное** состояние из этих команд, а не то, что помнишь из диалога.

## Что заполнить

- **Текущая задача** — одной фразой, с целью.
- **Состояние репозитория** — ветка, последний коммит, собирается или нет, что не закоммичено.
- **Что сделано** — по существу, без пересказа диалога.
- **Что осталось** — конкретные следующие шаги, а не направления.
- **Решения по ходу** — и допущение, на котором каждое стоит.
- **Открытые вопросы к разработчику** — то, что агент не вправе решить сам.

Добавь строку в таблицу внизу: дата, какой агент, итог.

## Правила

**Ссылайся на файлы, не вставляй код.** `HANDOFF.md` читается целиком каждым принимающим
агентом — вставленный код станет постоянным налогом на контекст и устареет за день.

**Не дублируй то, что уже есть в `AGENTS.md`.** Там правила проекта, здесь — состояние.
Одно и то же в двух местах расходится за неделю.

**Пиши так, чтобы принимающий проверил.** Он обязан сверить файл с `git status`
и сборкой прежде чем действовать: устаревший HANDOFF не авторитет над кодом.

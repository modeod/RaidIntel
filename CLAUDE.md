## Только для Claude Code

### Что использовать вместо ручного поиска

- **Субагент `rw-source`** — любой вопрос «как это устроено в ванили / есть ли такой класс /
  какая сигнатура». Он ищет в своём контексте и возвращает выжимку. Главная экономия
  контекста в этом проекте: `Assembly-CSharp` огромен, и его выдача в основной диалог
  съедает окно за один заход.
- **Скилл `/spike`** — когда надо проверить допущение из `docs/09_Assumption_Register.md`.
- **Скилл `/handoff`** — перед концом сессии или передачей работы Codex.

### Режим работы

Начинай с **plan mode** (`Shift+Tab`) для всего, что трогает архитектуру: точки крепления
в этом проекте переигрывались пять раз, и каждый раз дешевле было бы обсудить план.

### Инструкции для компактирования

При `/compact` сохраняй: текущую задачу и её цель · какие допущения проверены и с каким
результатом · какие файлы изменены и почему · что осталось несделанным.
Не сохраняй: содержимое прочитанных файлов игры, полные листинги, вывод сборки.
